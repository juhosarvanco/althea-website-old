# Althean sisällönmuokkaus — näin pääset alkuun

Tämä vie noin 15 minuuttia, ja teet sen vain kerran.

Tarvitset GitHub-tilin. GitHub on kirjautumistapa, ei työkalu jota sinun pitäisi
opetella — vähän niin kuin kirjautuisit Googlella. Kun tili on tehty, et käy
GitHubissa käytännössä enää koskaan: muokkaat tekstit suoraan Althean omalla
sivulla.

Tee tämä mieluiten yhdessä Juhon kanssa puhelimessa tai ruutua jakaen. Silloin
jos jokin kohta jumittaa, se selviää siinä samassa.

---

## 1. Luo GitHub-tili

Mene osoitteeseen **https://github.com/signup**

- **Sähköposti** — oma työsähköpostisi
- **Salasana** — jos käytät salasanojen hallintaa, luo salasana sinne
- **Käyttäjätunnus** — sovi Juhon kanssa etukäteen, niin sitä ei tarvitse
  keksiä kiireessä. Tunnus näkyy muutosten tekijänä.

GitHub lähettää sähköpostiisi vahvistuskoodin. Näppäile se.

Sivusto on englanniksi eikä siitä ole suomenkielistä versiota. Se ei haittaa —
tarvitset sitä vain nyt.

---

## 2. Ota kaksivaiheinen tunnistautuminen käyttöön

GitHub vaatii tämän kaikilta. Et pääse eteenpäin ilman.

Helpoin tapa on GitHubin oma puhelinsovellus:

1. Asenna **GitHub**-sovellus App Storesta tai Play Storesta
2. Kirjaudu siihen samoilla tunnuksilla
3. Valitse GitHubin asetuksissa kaksivaiheiseksi tavaksi **GitHub Mobile**

Jatkossa kirjautuminen vahvistetaan pelkällä ilmoituksella puhelimessa — ei
koodeja näppäiltäväksi.

---

## 3. Talleta palautuskoodit — älä ohita tätä

GitHub näyttää listan palautuskoodeja ja kysyy oletko tallentanut ne.

**Tallenna ne oikeasti.** Salasanojen hallintaan, tai tulosta paperille ja
laita talteen. Nämä koodit ovat ainoa tie takaisin tilille, jos puhelin katoaa
tai vaihtuu. Ilman niitä tili on lopullisesti poissa käytöstä.

Tämä on se kohta, jossa ihmiset useimmiten menettävät tilinsä myöhemmin.

---

## 4. Hyväksy kutsu Althean sivustolle

Juho lähettää sinulle kutsun sähköpostiin. Avaa se ja klikkaa
**Accept invitation**.

---

## 5. Kirjaudu ylläpitoon

Mene osoitteeseen **https://althea-retriitit.netlify.app/admin/** ja klikkaa
**Kirjaudu GitHubilla**.

GitHub kysyy kerran luvan. Ruudussa lukee jotain sen tapaista että sovellus saa
pääsyn repositorioihin — se kuulostaa isommalta kuin on. Kyse on Althean omasta
sivustosta ja siitä, että tekemäsi tekstimuutokset pääsevät tallentumaan.
Klikkaa vihreää nappia.

Laita sivu kirjanmerkkeihin. Tämän jälkeen pääset suoraan tänne.

---

## Sen jälkeen: miten muokkaat

| Nappi | Mitä tekee |
| --- | --- |
| **Muokkaa tekstiä** | Muokattavat tekstit saavat katkoviivareunuksen. Klikkaa ja kirjoita. |
| **Muutokset** | Näyttää listan siitä, mikä oli ennen ja mikä on nyt. |
| **Tallenna luonnos** | Tallentaa. **Ei näy vielä kenellekään.** Myös ⌘S. |
| **Esikatselu ↗** | Avaa sivun sellaisena kuin se näyttäisi julkaistuna. |
| **Julkaise** | Vie muutokset oikealle sivustolle. Näkyy noin minuutissa. |
| **Hylkää luonnos** | Heittää keskeneräiset muutokset pois. |

Muutamia asioita, joista voi olla hyvä tietää:

- **Et voi rikkoa sivuston ulkoasua.** Vain tekstit ovat muokattavissa — kuvat,
  värit, asettelu ja linkit eivät ole.
- **Mikään ei mene liveen vahingossa.** Tallentaminen ja julkaiseminen ovat eri
  napit. Voit tallentaa ja katsoa esikatselua niin monta kertaa kuin haluat.
- **Kaikki on peruttavissa.** Jokainen julkaisu tallentuu, ja Juho saa
  vanhan version takaisin yhdellä klikkauksella.
- **Enter ei toimi tekstin sisällä.** Se on tarkoituksellista: se estäisi
  asettelun rikkoutumisen.

Jos jokin ei toimi tai näyttää oudolta, kysy Juholta. Mitään ei voi tehdä niin
väärin ettei sitä saisi takaisin.
